# The WayMaker Project: Youth & Vocational Trades Curriculum

Hands-On Modular Rail, Edge Computing & Hardware Robotics

## Executive Overview
The WayMaker Project bridges real-world advanced rail infrastructure with accessible, hands-on STEM education. Designed for the Boys & Girls Club, vocational technical tracks, and local youth outreach, this program turns complex systems—distributed computing, mesh networking, and mechanical sensors—into digestible, career-ready learning modules.

## Program Structure: 4 Core Learning Pillars
1. The "Scare" (Sensors & Physical Mechanics)
2. The "Scarab" (Micro-Processing & Embedded Logic)
3. Signals & Community Mesh (RF & Emergency Alerts)
4. Enclosures, Fabrication & Silicon Security

## Vocational Pathway Alignment
| Grade / Level | Focus Area | Capstone Project |
|---|---|---|
| Middle School (Boys & Girls Club) | Intro to Sensors & Coding | Build a mini Scarab node that flashes lights when a buddy tag approaches. |
| High School / CTE Trade | Hardware Assembly & Mesh Setup | Wire a multi-node sensor array that relays vibration data down a model track. |
| Dual-Enrollment / College | Firmware, Security & Edge Data | Flash hardware keys to silicon and construct a secure, offline packet-processing mesh. |

## Immediate Goals
- Launch an educator-friendly prototype curriculum.
- Demonstrate real rail-inspired engineering concepts.
- Build student confidence into clear vocational pathways.
